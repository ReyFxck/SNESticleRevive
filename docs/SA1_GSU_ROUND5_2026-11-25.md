# SA-1 / SuperFX — round 5

Incremental on round4. No new ROM-specific workarounds or state format changes.

## SA-1

- The shared R5900 interpreter had six `sltiu ...,0x8000` comparisons.
  MIPS SLTIU sign-extends its immediate; the intended unsigned 16-bit boundary
  is now tested with a logical shift and the opposite branch polarity.
- MVN $00,$00 virtual refetch is limited to directly mapped ROM, with all
  three instruction bytes in the same 8 KiB mapping page. RAM-executed or
  page-boundary instructions use the ordinary refetch path.
- Power-of-two BW-RAM mirroring uses AND instead of modulo; irregular sizes
  retain modulo. This preserves the existing mirror mapping.
- Nonzero dividend / zero follows the measured SnesLab hardware results:
  quotient $FFFF for positive or $0001 for negative, unsigned magnitude as
  remainder. The exact 0/0 case was not established by the cited table and
  retains the previous behavior. Fullsnes notes conflicting reports; prefer
  the published cartridge measurements for the covered cases.
- MAC checks signed 40-bit overflow instead of unsigned carry. The existing
  per-operation flag lifetime remains unchanged, pending hardware testing.

## SuperFX

Code-cache refill resolves the backing ROM/RAM mirror once per 16-byte line,
then copies the contiguous bytes. A bytewise fallback preserves the behavior
for missing memory or irregular sizes that wrap inside a line. Alignment of
CBR and cache lines prevents crossing a logical 16-bit/LoROM boundary during
one refill. The pipeline, cache validity and MMIO indexing are unchanged.

## Validation

- Host SA-1 suite, including 65,535 nonzero divide-by-zero operands,
  signed MAC limits and 2,097,152 BW-RAM mirrored read/write pairs: PASS.
- Host GSU suite: 40,961 cache lines / 655,376 bytes, 17,960 ALU fuzz cases,
  and 98,304 pixel-plane cases: PASS.
- Both shared and plain CPU assembly compiled with generic Clang MIPS64r2
  n32. This is not a PS2DEV build or execution test.
- Existing CI already invokes both host chip suites and the linked CPU
  checker. Real R5900 SA-1-specific branch execution is not validated here.
